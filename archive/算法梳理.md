# 基于长期记忆与多智能体协作的任务自适应流式视频摘要算法设计

## 一、理解与抽象

### 1. 算法核心思想
本文考虑开放域视频摘要任务。不同于传统方法对所有视频采用统一的重要性评分标准，本文方法将视频摘要建模为一个**任务自适应、长期记忆增强、流式顺序处理、多智能体协同决策**的问题。其核心思想是：首先对整段视频建立全局主题理解与故事流表示，然后在滑动窗口框架下顺序处理局部内容，并由一个总规划 Agent 根据视频主题动态生成摘要目标、设计关注点、调度专家 Agent，对每个视频片段进行面向目标的边际价值评估，最终输出符合视频语义特征的摘要结果。

### 2. 算法解决的问题
该算法主要解决以下问题：

- 不同视频类型对应不同摘要目标，传统统一评分机制难以适配；
- 长视频难以直接进行全局细粒度建模；
- 视频摘要不仅要保留高光内容，还需保留主线推进内容；
- 现有方法常忽略流式处理条件下历史信息对当前决策的影响。

### 3. 输入与输出

#### 输入
- 原始视频序列 $V=\{f_t\}_{t=1}^{T}$
- 可选辅助信息：标题、ASR、类别标签
- 参数：窗口长度 $L$、重叠长度 $O$、采样间隔 $r$、摘要预算 $B$

#### 输出
- 帧级重要性分数序列 $S=\{s_t\}_{t=1}^{T}$
- 选中的摘要片段集合 $Y$
- 可选的多智能体决策解释信息

### 4. 相较于已有方法的创新点
本文方法相较于已有视频摘要方法，潜在创新体现在以下几个方面：

1. **动态摘要目标建模**：根据视频主题自适应调整摘要策略，而非固定摘要标准；
2. **双时间尺度建模**：结合全局低频理解与局部高频滑动窗口分析；
3. **多智能体专家协作**：通过专家分工提升可解释性与目标适配能力；
4. **长期记忆引导的边际增益评估**：利用历史记忆抑制冗余并强化故事线保持。

### 5. 整体系统结构
整个算法系统可划分为五个层级：

1. 全局语义理解层  
2. 局部流式感知层  
3. 长期记忆与任务规划层  
4. 多专家协同推理层  
5. 分数修正与摘要生成层

## 二、算法结构化设计

## 2.1 模块划分

### （1）输入模块
输入模块负责将原始视频转化为适合后续处理的时序单元，主要包括：

- 视频粗粒度分段；
- 镜头划分或定长切分；
- 滑动窗口构建；
- 均匀采样关键帧。

输出结果包括：
- 全局分段集合 $\{G_j\}$
- 滑动窗口集合 $\{W_i\}$

### （2）感知模块
感知模块分别提取全局语义表示与局部窗口表示。

#### 全局语义建模
对每个粗分段 $G_j$，通过 Video LLM 生成片段描述：

$$
c_j^g = \text{VideoLLM}(G_j)
$$

再通过 LLM 聚合所有粗分段描述，得到整段视频的全局文本摘要：

$$
m^g = \text{LLM}_{agg}(\{c_j^g\}_{j=1}^{N_g})
$$

#### 局部窗口感知
对每个滑动窗口 $W_i$，均匀采样帧集合 $X_i$，生成局部 caption：

$$
c_i = \text{VideoLLM}(X_i)
$$

视觉特征表示为：

$$
v_i = \phi_v(X_i)
$$

文本特征表示为：

$$
t_i = \phi_t(c_i)
$$

最终融合成局部多模态表示：

$$
h_i = \text{Fuse}(v_i, t_i)
$$

### （3）推理模块
推理模块由总规划 Agent 和多个专家 Agent 组成。

#### 总规划 Agent
总规划 Agent 的职责包括：

- 理解视频整体主题与摘要任务；
- 生成动态摘要目标；
- 设计关注点；
- 对专家 Agent 进行任务分发；
- 汇总专家结论并生成窗口权重。

设视频主题分布为：

$$
\hat z = p(z \mid m^g)
$$

摘要目标向量为：

$$
q = \Psi(m^g, \hat z)
$$

在处理第 $i$ 个窗口时，总规划 Agent 根据当前窗口表示、全局目标和长期记忆，输出专家路由权重：

$$
\alpha_i = \text{softmax}(W[h_i; q; \text{Read}(M_{i-1})])
$$

#### 专家 Agent 设计
建议设置如下专家：

1. **主线推进专家** $E^{main}$：判断当前窗口是否推动视频主线发展；
2. **事件高光专家** $E^{event}$：评估窗口是否包含关键事件或高潮；
3. **新颖性专家** $E^{nov}$：判断窗口信息是否与历史内容重复；
4. **时序连续性专家** $E^{temp}$：保证摘要整体观看体验与叙事连续性；
5. **领域策略专家** $E^{dom}$：根据视频类型采用不同的摘要偏好。

每个专家输出一个局部得分：

$$
a_i^{(k)} = E^{(k)}(h_i, q, M_{i-1})
$$

窗口基础分数由加权求和得到：

$$
r_i = \sum_{k=1}^{K} \alpha_i^{(k)} a_i^{(k)}
$$

### （4）决策模块
决策模块负责将窗口级分数映射到帧级分数，并在预算约束下选择最终摘要片段。

帧级分数由重叠窗口融合得到：

$$
s_t = \frac{\sum_{i: t \in W_i} \omega_{i,t} r_i}{\sum_{i: t \in W_i} \omega_{i,t}}
$$

最终摘要选择满足预算约束：

$$
Y^* = \arg\max_Y \sum_{t=1}^{T} s_t y_t
\quad \text{s.t.} \quad \sum_t y_t \le B
$$

### （5）输出模块
输出模块生成：

- 帧级重要性得分曲线；
- 片段级摘要结果；
- 最终摘要视频；
- 多 Agent 决策解释日志。

## 三、完整数据流

整体数据流可描述如下：

1. 原始视频进行粗分段；
2. 使用 Video LLM 对粗分段生成 caption；
3. 聚合所有 caption 获得视频全局主题与故事流；
4. 视频按滑动窗口顺序处理；
5. 每个窗口均匀采样并生成局部 caption 与视觉特征；
6. 长期记忆模块读取历史信息；
7. 总规划 Agent 根据全局目标和当前窗口内容生成任务路由；
8. 各专家 Agent 对当前窗口进行专项评估；
9. 汇总得到窗口重要性分数；
10. 通过分数修复机制进行平滑与重叠融合；
11. 生成帧级重要性序列并在预算约束下生成摘要。

## 四、关键步骤公式化

### 4.1 主线推进分数
主线推进专家评估当前片段是否对整体叙事主线产生新的推进作用，可定义为：

$$
a_i^{main} = \text{sim}(h_i, q_{story}) - \max_{m \in M_{i-1}^{story}} \text{sim}(m, q_{story})
$$

### 4.2 新颖性分数
新颖性专家评估当前内容与已有记忆的差异性：

$$
a_i^{nov} = 1 - \max_{m \in M_{i-1}} \text{sim}(h_i, m)
$$

### 4.3 领域策略分数
领域策略专家根据视频类别或主题软分布进行评价：

$$
a_i^{dom} = E^{dom}(h_i, \hat z)
$$

### 4.4 最终窗口分数
总体窗口得分为多专家分数的动态加权组合：

$$
r_i = \lambda_1 a_i^{main} + \lambda_2 a_i^{event} + \lambda_3 a_i^{nov} + \lambda_4 a_i^{temp} + \lambda_5 a_i^{dom}
$$

也可采用动态生成权重：

$$
\lambda = \text{softmax}(g(h_i, q, M_{i-1}))
$$

## 五、强化创新点

### 5.1 核心创新点
本文算法真正有价值的创新点可归纳为三点：

1. **任务自适应摘要目标建模机制**  
   从全局视频语义中自动诱导摘要目标，而非采用固定的摘要偏好。

2. **双时间尺度流式摘要框架**  
   通过“全局粗理解 + 局部滑动窗口”的不对称结构兼顾叙事完整性与长视频处理效率。

3. **长期记忆增强的多智能体边际贡献评估机制**  
   不再将每个片段视作独立样本，而是评估其相对于已有记忆的新增贡献。

### 5.2 学术化表达
本文可将贡献表述为：

> 本文针对开放域视频摘要中的目标异质性问题，提出一种长期记忆增强的任务自适应多智能体流式视频摘要框架。该框架通过全局语义规划、局部顺序处理与专家协同推理，显式建模片段对摘要目标的边际贡献，从而生成更符合视频语义特征的摘要结果。

### 5.3 为什么这些创新有效
这些创新有效的原因在于：

- 动态摘要目标避免了不同视频类别被统一标准误判；
- 全局规划让局部打分具备主线意识；
- 长期记忆显著降低冗余片段重复入选概率；
- 多智能体协作提高了决策的解释性和可迁移性。

## 六、算法不足与改进

### 6.1 可能存在的问题

#### （1）严格意义上的流式性不足
若算法在开始前访问了全视频全局信息，则其更接近离线流式处理而非纯在线处理。

**改进方案**：  
设置两种实验协议：

- Offline-Streaming：允许全局预览；
- Online-Streaming：只利用已观测历史构建动态全局目标。

#### （2）对 Video LLM caption 的依赖较强
若 caption 存在幻觉或偏差，将影响后续多 Agent 判断。

**改进方案**：  
加入视觉-文本一致性校验项：

$$
c_i^{cons} = \text{sim}(\phi_v(X_i), \phi_t(c_i))
$$

对低一致性窗口降低文本特征权重。

#### （3）推理成本偏高
多 Agent + 多轮 LLM 调用在长视频场景下开销较大。

**改进方案**：

- 使用轻量级模型进行窗口粗筛；
- 仅对候选窗口执行完整专家推理；
- 将 Agent 决策蒸馏到轻量打分网络。

#### （4）泛化性风险
不同数据域之间摘要策略差异较大，模型可能在跨域测试时退化。

**改进方案**：

- 使用软主题混合策略而非离散类别；
- 补充跨域泛化实验；
- 增加窗口长度、重叠比例、LLM 类型的鲁棒性分析。

## 七、新增互补创新模块

### 7.1 模块名称
**反事实边际贡献评论家（Counterfactual Marginal Contribution Critic, CMCC）**

### 7.2 模块动机
虽然多 Agent 可以给出多视角评分，但仍缺少一个统一判别标准，即：**如果当前窗口被删除，最终摘要会损失多少关键信息？**

### 7.3 模块定义
设当前长期记忆为 $M_{i-1}$，当前窗口表示为 $h_i$，摘要目标为 $q$，则反事实边际贡献定义为：

$$
\Delta_i^{cf} = U(M_{i-1} \cup h_i, q) - U(M_{i-1}, q)
$$

其中 $U(\cdot)$ 表示在摘要目标 $q$ 下的整体信息效用函数。

### 7.4 与原方法的互补性
该模块与原始方法互补体现在：

- 原方法关注多视角局部打分；
- CMCC 关注当前片段的不可替代性；
- 二者结合后可进一步减少冗余、增强覆盖并提高主线完整性。

### 7.5 加入后的新评分公式
加入 CMCC 后，最终窗口评分为：

$$
r_i' = r_i + \gamma \Delta_i^{cf}
$$

## 八、最终算法设计

## 8.1 整体框架
最终算法可命名为：

**MATSum+CMCC: Memory-Augmented Task-adaptive Multi-Agent Streaming Video Summarization with Counterfactual Critic**

整体流程包括：

1. 全局语义理解；
2. 局部滑动窗口感知；
3. 长期记忆维护；
4. 总规划 Agent 动态调度；
5. 专家 Agent 协同评估；
6. 反事实边际贡献校准；
7. 分数修复与摘要生成。

## 8.2 最终关键公式

### 全局语义摘要

$$
m^g = \text{LLM}_{agg}(\{c_j^g\})
$$

### 摘要目标生成

$$
q = \Psi(m^g)
$$

### 局部表示提取

$$
h_i = \text{Fuse}(\phi_v(X_i), \phi_t(c_i))
$$

### 多专家评估

$$
a_i^{(k)} = E^{(k)}(h_i, q, M_{i-1})
$$

### 路由权重

$$
\alpha_i = \text{softmax}(W[h_i; q; \text{Read}(M_{i-1})])
$$

### 基础聚合分数

$$
r_i = \sum_k \alpha_i^{(k)} a_i^{(k)}
$$

### 反事实校准

$$
\Delta_i^{cf} = U(M_{i-1}\cup h_i, q) - U(M_{i-1}, q)
$$

### 最终分数

$$
r_i' = r_i + \gamma \Delta_i^{cf}
$$

### 帧级映射

$$
s_t = \frac{\sum_{i:t\in W_i} \omega_{i,t} r_i'}{\sum_{i:t\in W_i}\omega_{i,t}}
$$

## 九、算法流程描述

1. 将视频粗分段并生成全局片段描述；
2. 聚合全局 caption 形成视频主题与故事主线表示；
3. 使用滑动窗口顺序处理视频；
4. 对每个窗口生成局部 caption 和多模态 embedding；
5. 从长期记忆读取已有主线、冗余和上下文信息；
6. 总规划 Agent 输出专家权重和任务关注点；
7. 各专家 Agent 对窗口进行专项打分；
8. 反事实评论家估计窗口的真实边际贡献；
9. 对窗口得分进行时序平滑与重叠融合；
10. 生成帧级重要性曲线并依据预算选择摘要片段；
11. 输出最终摘要视频。

## 十、算法伪代码

```python
def MATSum(video, budget, win_len, overlap, sample_rate):
    global_segments = coarse_split(video)
    global_captions = [VideoLLM(seg) for seg in global_segments]
    global_story = LLM_aggregate(global_captions)
    theme_dist, summary_goal = Planner.init_plan(global_story)

    windows = sliding_windows(video, win_len, overlap)
    memory = MemoryBank()
    window_scores = []

    for w in windows:
        frames = uniform_sample(w, sample_rate)
        local_caption = VideoLLM(frames)
        visual_feat = VisualEncoder(frames)
        text_feat = TextEncoder(local_caption)
        h = fuse(visual_feat, text_feat)

        mem_state = memory.read()
        route_weights = Planner.route(h, summary_goal, mem_state)

        score_main = MainlineAgent.score(h, summary_goal, mem_state)
        score_event = EventAgent.score(h, summary_goal, mem_state)
        score_novel = NoveltyAgent.score(h, summary_goal, mem_state)
        score_temp = TemporalAgent.score(h, summary_goal, mem_state)
        score_domain = DomainAgent.score(h, theme_dist, mem_state)

        expert_scores = [
            score_main, score_event, score_novel, score_temp, score_domain
        ]
        base_score = weighted_sum(route_weights, expert_scores)

        cf_gain = CounterfactualCritic.score(memory, h, summary_goal)
        final_score = base_score + gamma * cf_gain

        window_scores.append(final_score)
        memory.update(h, local_caption, final_score)

    frame_scores = overlap_fusion(window_scores, windows)
    frame_scores = temporal_smoothing(frame_scores)
    summary = budgeted_selection(frame_scores, budget)

    return summary, frame_scores
```

## 十二、总结
该算法的关键不在于简单地引入多个 Agent，而在于：

1. 让摘要目标随视频语义动态变化；
2. 让局部判断受全局主线和长期记忆约束；
3. 让多专家协同评估当前片段对最终摘要的边际价值。

因此，该方法可被视为一种从“统一重要性排序”范式转向“目标条件化边际贡献估计”范式的视频摘要方法，具有较强的方法创新性和论文扩展潜力。
